# Standing instruction — the upgrade menu (Hassan, 2026-06-12)

At every milestone (PR merged, feature shipped, phase done) — in ANY project —
do NOT pick the next piece of work unilaterally. Instead:

1. Present a ranked menu of the next possible upgrades.
2. For each: **impact** (what visibly/strategically changes, for whom) and
   **effort** (rough size — S/M/L or PR count).
3. Recommend one, briefly say why, then WAIT for Hassan's pick.

He decides what's next. Always. This applies across Claude, Cowork and
Claude Code sessions and all projects in this repo and beyond.
